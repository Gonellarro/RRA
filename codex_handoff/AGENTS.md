# Instrucciones para esta carpeta de continuidad local

Lee `CONTEXTO_RRA.md`, `ESTADO_ACTUAL.md`, `INSTRUCCIONES_CODEX_REMOTO.md` y
`PLAN_SIGUIENTES_PASOS.md`. El proyecto existente está en `C:\RRA`; no crees
otro checkout ni supongas que un worktree contiene estos archivos ignorados.
Puedes acceder a la Orange Pi por SSH según las instrucciones; comprueba el
estado antes de modificar y registra operaciones y resultados reales aquí.
No hagas commit, push, ramas, PR ni sincronices estos archivos con servicios
externos. No cambies red, SSH, claves o contraseñas sin autorización. No
controles motores o actuadores. Mantén esta documentación local actualizada.

Este archivo solo se aplica a esta carpeta; al trabajar en el resto del proyecto
lee expresamente estas normas y los documentos indicados al comienzo de sesión.
